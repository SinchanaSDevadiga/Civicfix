# 🏙️ CivicFix – Smart Civic Issue Reporting

### Report. Track. Improve.

CivicFix is a web-based platform that helps citizens report civic problems and track their complaints, contributing to cleaner, safer and better communities.

## 🚀 Features

- 📝 Report civic issues
- 📸 Upload complaint photos
- 📍 Detect current location
- 🗺️ View locations using Google Maps
- 🔍 Search and filter complaints
- 📊 Dashboard with complaint statistics
- 🔄 Track complaint status
- 👨‍💼 Admin dashboard for managing reports
- 💾 Local Storage for saving reports

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage
- Google Maps Links

## 🎯 Purpose

To encourage citizens to participate in improving their communities by making civic issue reporting simple and accessible.
